Build states

6 total / 4 settled

  1. 00settled

    PROVISIONED

    One x86 box in Mumbai, Ubuntu 24.04. Two firewalls, three ports open, root login disabled. No managed platform — if it breaks, it's mine to fix.

  2. 01settled

    TLS_ISSUED

    Certificates issued and renewing on their own, edge cache in front. The boring part, done properly, once.

  3. 02settled

    SERVING

    First bytes over TLS. Static files, one container, no framework — proving the pipe worked before putting anything real in it.

  4. 03settled

    API_LIVE

    A Go binary serves this page from its own embedded filesystem, behind a reverse proxy it never talks to directly. Push to main and it ships itself — build, health check, swap. /api/health will tell you which commit you're reading.

  5. 04current

    OSM_SANDBOX

    An order state machine you can drive yourself — and then break. Kill the vendor mid-flight, replay a webhook twice, watch it recover.

  6. 05pending

    TELEMETRY

    A public dashboard for this box. Request rate, p99, error budget. Nothing hidden, including the bad numbers.
